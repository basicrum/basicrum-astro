## Architecture verdict

The integration follows Astro's supported extension model. Keep
`astro:config:setup`, `injectScript("head-inline", bootstrap)` and the
prerendered injected Boomerang route in `src/index.ts:17-44`. A classic head
script preserves the vendored loader's execution semantics and early start
time. A bundled module would change that timing; `before-hydration` is tied
to hydrated islands and does not serve pages without them.

The bootstrap configures synchronously and starts the selected loader.
Boomerang loads asynchronously and need not be initialized before islands.
The framework-neutral core, explicit loader choice, duplicate registration
failure and disabled-by-default development behavior remain appropriate.
Non-consent intentionally starts without a consent decision; consent waits
for the site's manager.

The Partytown, Alpine and Sentry comparison was supplied from Codex's preceding
source review. Fable verified Astro's installed implementation rather than
independently fetching those integrations.

## Low priority recommendations

### P3 coverage for ordering before islands

`README.md:52-53` promises execution before Astro islands. The adapter unit
tests check the injection stage and script syntax, but no fixture contains
a hydrated island. Add a fixture whose island records whether the bootstrap
guard and configuration already exist when hydration runs. This would prove
the guarantee directly without requiring Boomerang's download to finish.

A structural assertion that the bootstrap is a classic inline script inside
`head` is useful narrower coverage. Do not assert that it must be the first
script in the document: Astro can emit a deferred module before it, and a
site can supply earlier inline scripts. No incorrect runtime ordering was
established.

### P3 deployment documentation recommendation

`README.md:168-170` already explains that static hosts control cache headers.
An additional sentence could explain that the Node adapter's middleware mode
requires serving the client output directory under Astro's base. Standalone
mode handles static files itself. This is an existing deployment prerequisite,
not a defect in a correctly configured installation. See the official
[Node adapter middleware guide](https://docs.astro.build/en/guides/integrations-guide/node/#middleware).

Do not label the response headers in `src/boomerang-endpoint.ts:12-16` as
universally "dev-only". Astro can expose prerendered headers to adapters
through `routeToHeaders`; preservation depends on the adapter and host. The
installed Node adapter currently forwards only CSP from that map, so its
`staticHeaders` option alone does not establish preservation of Basicrum's
cache, content type and nosniff headers.

## Confirmed strengths and remaining limits

Existing tests cover both real loaders, configured beacon metadata, non-root
base paths, static output, Node SSR, explicit dev enablement, download races,
queued sends, cookie removal and delayed beacons with local unload traffic.
The guard preserves withdrawn configuration when a bootstrap is replayed.
Safe serialization and the framework boundary are also tested.

Optional additions are a browser test under `security.csp`, fallback page
type without metadata, a root-base browser variant and a non-consent
ClientRouter swap. Astro's source hashes injected head scripts, but that is
not browser evidence for every CSP policy or the iframe fallback. Serializing
only the options consumed by the bootstrap is a small optional size saving.

The documented limits remain: full document loads only, no soft-navigation
measurements, no beacon for visits ending before load, no tested back-forward
cache restoration, and a full reload to re-grant after withdrawal. Browser
coverage is Chromium only; third-party consent managers and non-Node adapters
are outside the current suite.

Fable withdrew the proposed cleanup of historical ignored build directories.
They were not used as evidence of current behavior. Only this review record
was added; no runtime fix, test edit, commit or publication was performed.
